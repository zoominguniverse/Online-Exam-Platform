# Spec Delta

## Purpose

规定管理员建立学科和五类题库的业务行为，以及题干中的文本、图片、表格和数学公式的呈现约束，让组卷、作答和历史复习共享一致的题目内容。

## ADDED Requirements

### Requirement: QB01 学科管理
管理员 SHALL 按年级查询、新增、编辑和删除学科。同年级规范化名称唯一，学科须属于有效年级。存在题目或试卷引用时删除 SHALL 返回引用冲突。

#### Scenario: QB01-N 学科生命周期
- **WHEN** 管理员创建学科、修改名称并删除未引用学科
- **THEN** 查询反映每次变化，已删除学科不能用于新题目

#### Scenario: QB01-F 非法和被引用学科
- **WHEN** 使用无效年级、重复名称或删除被引用学科
- **THEN** 请求失败并说明字段错误或引用原因，现有引用可继续读取

### Requirement: QB02 五类题目管理
管理员 SHALL 查询、创建、编辑、删除单选、多选、判断、填空、简答题。题目包含学科、难度、正分值、题干、参考答案和解析。单选须有一个有效答案，多选至少两个不同正确选项，判断须为二值，填空答案数量匹配空位，简答须有参考内容。

#### Scenario: QB02-N 五题型创编
- **WHEN** 管理员分别保存五类有效题目并按学科、题型筛选
- **THEN** 返回正确题型及完整内容，各题可加入同年级试卷

#### Scenario: QB02-F 内容校验
- **WHEN** 分值为负或零、正确选项不存在、空位数量不匹配或学科无效
- **THEN** 保存失败并定位错误字段，不产生部分题目记录

#### Scenario: QB02-B 已引用题目编辑删除
- **WHEN** 编辑或删除已被发布试卷引用的题目
- **THEN** 编辑产生新版本，删除归档主记录，旧试卷及答卷仍能读取原版本，新组卷无法选择已归档题目

### Requirement: QB03 富文本与附件
管理端预览与学生 Web SHALL 呈现净化后的文本、图片、表格及数学公式。上传图片限 PNG、JPEG、WebP 且不超过 5 MiB，文件类型由内容校验。附件读取 SHALL 校验业务归属和可见性，作答响应不包含参考答案或解析。

#### Scenario: QB03-N Web 内容呈现
- **WHEN** 管理员保存并预览混合内容题干，学生在 Web 打开相同试卷
- **THEN** 表格结构、图片和公式含义一致，长内容可滚动且不遮挡答题控件

#### Scenario: QB03-F 不可信内容
- **WHEN** 提交脚本、事件属性、危险链接、伪装图片或超限文件
- **THEN** 危险富文本被净化或拒绝，非法文件拒绝且不形成可访问附件

#### Scenario: QB03-B 答案与图片授权
- **WHEN** 未登录用户读取私有图片，或作答学生检查接口响应
- **THEN** 未授权图片不可读，作答响应不包含参考答案、解析和答案图片引用
