# Spec Delta

## Purpose

规定管理员按年级发布含多张试卷的任务，以及学生逐卷完成任务的规则，确保Web 多会话恢复、重复请求和并发开始均不会增加一次性任务试卷的作答机会。

## ADDED Requirements

### Requirement: TA01 多试卷年级任务
管理员 SHALL 查询、创建、编辑、发布和删除年级任务。发布须包含至少一张同年级已发布任务试卷，且冻结卷版本和当时启用的目标年级学生名单。每张任务试卷只能绑定一个已发布任务，复用须创建新的试卷标识。

#### Scenario: TA01-N 发布两张试卷
- **WHEN** 管理员发布包含 A、B 两张任务试卷的任务
- **THEN** 目标学生看见两项待完成记录，非目标学生不能访问

#### Scenario: TA01-F 错误成员
- **WHEN** 任务包含其他年级、普通练习卷、重复卷或已绑定其他任务的卷
- **THEN** 整体发布失败，资格和任务内容均不产生部分变更

#### Scenario: TA01-B 发布后的资格
- **WHEN** 发布后新增同年级学生或已有目标学生调整年级
- **THEN** 新学生不自动获得旧任务，原目标学生保留资格，账号禁用仍阻止访问

### Requirement: TA02 每学生每任务试卷一次
同一学生对同一任务试卷 SHALL 最多有一份答卷。未提交时重新进入恢复原答卷，提交或完成后仅允许批改或回看。完成 A 卷 SHALL 不影响 B 卷的开始资格。

#### Scenario: TA02-N 分别完成
- **WHEN** 学生完成 A 卷并开始 B 卷
- **THEN** B 卷可正常开始，A 卷只能回看，任务显示逐卷完成进度

#### Scenario: TA02-B Web 多会话并发开始
- **WHEN** 同一学生从两个独立 Web 会话同时开始同一任务试卷
- **THEN** 两个请求返回同一个答卷标识，数据库只存在一份答卷

### Requirement: TA03 任务状态与归档
任务 SHALL 在全部试卷答卷最终完成后显示已完成，待自行批改卷计为未完成。已发布任务内容和资格冻结，删除表现为归档并阻止尚未开始的作答，已开始答卷和历史结果保留。

#### Scenario: TA03-N 待批改进度
- **WHEN** 两张卷均提交，其中一张仍待自行批改
- **THEN** 任务显示一张已完成及一张待批改，后者确认成绩后任务完成

#### Scenario: TA03-F 修改已发布任务
- **WHEN** 管理员尝试增删已发布任务的卷或资格名单
- **THEN** 请求拒绝并提示新建任务，既有完成记录不变
