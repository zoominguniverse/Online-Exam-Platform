# Web 保存与截止证据（2026-11-11）

运行 `node scripts/test-browser.mjs`，使用 Node 22.22.2、Playwright 1.65.0、真实 Chromium 158.0.8127.18、Java 21 与独立 PostgreSQL 17.11。测试通过真实 Vue 页面登录、开始与编辑；API 和答案存储没有替身。每次记录时直接查询本轮 PostgreSQL 核对答案与版本，见 [摘要](summary.json)。账号、题目和答案均为隔离生成的测试数据。

| 截图 | 实际验证 |
| --- | --- |
| [保存后刷新](saved-refresh.png) | 五题型收到保存确认，刷新后答案和截止不变 |
| [断网待同步](offline-pending.png) | 浏览器上下文离线，服务器无新答案，本地草稿仍在 |
| [重连恢复](online-recovered.png) | 网络恢复后核对服务端，匹配版本保存，确认后清除草稿 |
| [双会话冲突](version-conflict.png) | 独立浏览器会话中的旧版本被拒绝，页面保留本地答案并展示服务器答案；随后显式加载服务端版本 |
| [响应丢失后继续编辑](lost-response-reconciled.png) | `route.fetch()` 先让真实 API 提交，再中断返回；后续读取核对旧请求后保存较新输入，版本为 3 |
| [账号切换](account-switch.png) | 另一标签登录另一账号时移除旧草稿、隐藏旧内容，延迟保存响应不恢复旧页面 |
| [停机重启后截止](restart-deadline.png) | 实际停止并重启独立 API；停机期间只将本测试答卷截止改为开始后 1 ms，先在数据库确认调度冻结，再联网；仅停机前确认的答案计入，未确认输入明确提示不计入 |

这是本地真实浏览器与实际服务进程的验证；网络断开/响应中断为受控故障注入。重启用例缩短了隔离测试数据的截止时间，没有改变系统时钟、旧迁移或业务运行逻辑，也没有模拟 Java 服务响应。客户端时钟更改、长时间后台、微信体验版、跨真实 Web/微信恢复和完整提交/批改页面仍未验收。

完整 Playwright 机器报告与日志保存在本机忽略的 `tmp/exam-browser-*/evidence/`。本目录保留最终成功轮次的摘要、截图与 [六项测试结果](test-results.json)；摘要内的项目名、时间和 UUID 将它们关联到同一次执行。测试结束仅删除本次项目的容器和数据库/附件卷。
